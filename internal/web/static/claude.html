Cache writes cost 1.25× the input rate (5-minute cache) or 2× (1-hour cache). Cache reads cost 0.1× input, except 0.05× on Opus 5.5 and Sonnet 5.5 and 0.025× on Fable 5.1. Input cost adds uncached input, cache writes and cache reads, each at its own rate; output cost is output tokens at the output rate. Not included: web searches ($10 per 1,000) and the 1.1× surcharge for US-only inference. * Haiku 5.5 charges 5× these rates for any request whose prompt is over 100,000 tokens. The export has no per-request sizes, so the lower rate is used and Haiku 5.5 cost may be understated. Anthropic also publishes claude.com/pricing ↗ as the most current summary.

How to read these numbers

The spend report has one row per account, product and model for the whole exported range; it has no daily breakdown, so this page compares people rather than showing trends. The date range comes from the file name (…-YYYY-MM-DD-to-YYYY-MM-DD.csv).

Input tokens are the sum of uncached input, cache reads, and cache writes (5-minute and 1-hour). Total tokens add output. Cache hit rate is cache reads divided by all input tokens.

Seat-plan usage shows $0 spend in the export, so “Est. API cost” prices the same tokens at Anthropic's public API list rates (October 2026). It shows relative weight, not what the company is billed. Models without a known price are excluded from the estimate and named on the cost card.

With “Combine numbered accounts” on, an address whose name ends in C followed by digits (jane.doeC3@…) is counted with the same address without the suffix. Hover a person's row in the table to see which accounts were combined.
